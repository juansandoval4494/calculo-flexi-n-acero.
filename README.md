# Diseñador de Vigas de Acero Estructural (Flexión)

Herramienta interactiva en Python / Streamlit para el diseño y revisión de elementos de acero sometidos a flexión.

## Estructura de Carpetas

- `data/`: Coloca aquí el catálogo de perfiles (archivos `.csv` o `.xlsx` de perfiles IPR, W, canales, HSS, etc.).
- `docs/`: Coloca aquí los manuales de fórmulas (PDFs, imágenes o notas de texto de AISC 360, IMCA, NTC, etc.).
- `examples/`: Ejemplos del cuaderno para comparar y calibrar resultados.
- `src/`: Módulos de cálculo (estados límite de flexión, pandeo lateral torsional, deflexiones, cortante).
- `app.py`: Aplicación web interactiva.
